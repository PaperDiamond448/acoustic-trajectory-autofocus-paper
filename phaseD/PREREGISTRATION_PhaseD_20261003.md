## 0. 背景与范围

当前方法（BTA）在 VIT 锚轨迹附近用 21 个节点（15 s 间隔）、±0.02 Hz 盒界修正频率轨迹。本轮回答四个问题：

1. 节点间隔应取多少（精度–计算量折中）？
2. 修正半径是否应在盒界持续限制解时逐级放宽（local-first 自适应扩张）？
3. 方法在不同积累时长、不同粗轨迹前端下是否仍有增益？
4. 在多条真实线谱、多个时段上是否仍有增益？

采用两阶段设计：**开发阶段**（D1、D2）只用开发种子选参数，按本文写定的规则冻结方法；**确认阶段**（C）在全新种子上检验冻结后的方法；确认后方法不再改动，原样用于**外部验证**（X1 时长、X2 跨前端、X3 实测）。

已有事实（只作设计依据，不作本轮结论）：

- E4a（`phaseC/E4a_formal_paired_20260925/`，400 个种子，phase 33）已被用于设计扩张规则，**不得再作为自适应规则的检验数据**。
- 事后分析（`phaseC/E4a_posthoc_box_activity_20260929/`）显示：去盒界解超出 0.02 Hz 的比例为 S2 100%、S0 66%；有界解的“最长边界驻留时长”比“触边节点数”更能预示放宽后的 η 收益（合并 Spearman 0.51 对 0.42；14 个单元中位数 0.48 对 0.34，最小值 +0.13 对 −0.29）。因此**触发量冻结为最长边界驻留时长**（§2.6），阈值留给 D2。
- 驻留时长能把扩张引向盒界真正限制解的记录，但不能识别放宽后会变差的记录。论文中只能写前一种作用。

### 2.4 正则项的物理尺度

现有罚项为 `λ/(P−2)·‖D₂u‖²`（BTA：λ_C=1e-3；SMR：λ_F=0.1）。节点间隔或时长改变时，这一形式对应的平滑强度会变。本轮把罚项固定为**单位时长的平均曲率平方**：分段线性修正在节点 p 处的二阶差分为 `r·(D₂u)_p/Δ²`，于是

```
mean curvature² ≈ r² Σ(D₂u)² / (T Δ³)
```

令逐项权重 `w(Δ,T) = λ/(P−2)` 满足 `w(Δ,T) = w₀ · (T₀/T) · (Δ₀/Δ)³`，其中 `w₀ = λ₀/(P₀−2)`，`Δ₀=15 s, T₀=300 s, P₀=21`。实现时令

```
lambda(Δ,T) = λ₀ · (P−2)/(P₀−2) · (T₀/T) · (Δ₀/Δ)³        （λ₀ = 1e-3 用于 BTA，0.1 用于 SMR）
```

Δ=15、T=300 时 λ 不变（G5）。数据项 Q（按记录能量归一）和 SMR 拟合项（按帧数归一）都与时长无关，所以罚项也按单位时长归一。

D1 另设**未缩放对照臂**（仍用 `λ₀` 不变）检验结论是否依赖这一缩放（§3.2）。

### 2.5 修正半径的实现

基函数尺度固定 `r = 0.02 Hz`，**只改系数上下界**：

- 固定半径 ρ：`|u_p| ≤ ρ/0.02`（ρ = 0.01/0.02/0.04/0.08 → 0.5/1/2/4）
- 去盒界：`u` 上下界为 ±Inf，保留全局频带约束 `Aineq/bineq`（与 E4a 相同）
- SMR 起点始终是 `|u| ≤ 1`、局部搜索半径 0.02 Hz 的原 SMR，不随半径改变

这样各半径之间目标函数、正则强度（以 Hz 计）、起点完全相同，只有可行域不同。

### 2.6 边界驻留时长（触发量，已冻结）

给定解 u 与逐节点上界向量 `m`（全局扩张时各元素相同）：

```
a(t_n) = |B(t_n) u|,  b(t_n) = B(t_n) m,   t_n ∈ 评价区间 [5, T−5)，按基带采样率 20 Hz 取样
at_bound(t_n) = a(t_n) ≥ 0.95 · b(t_n)
dwell runs   = at_bound 为真的极大连续段，长度以秒计（样点数/20）
D(u, m)      = 最长连续段的长度（秒）
```

同号要求自动满足（跨零必然断开连续段）。

### 2.7 自适应扩张算法（ADA）

参数：驻留阈值 τ（秒）、上限 cap ∈ {0.04, 0.08} Hz（级别序列 `L = [1, 2]` 或 `[1, 2, 4]`）、模式 ∈ {global, local}、重跑方式 ∈ {A, B}。

```
输入: y, fe, 族 fam(Δ*, r=0.02), 起点 u0 (VIT–SMR 时为 SMR 系数, 其他前端为 0)
第 0 轮: m = 1(全部节点);  u ← estimate_proposed(..., u0, 上下界 ±m)       # 与固定 0.02 完全相同
for 轮次 k = 1 .. numel(L)−1:
    runs ← 驻留连续段(u, m);  S ← {长度 ≥ τ 的段}
    if S 为空: break
    global: 若 m 已到 cap 则 break；否则 m ← L 中下一级(全部节点)
    local : N ← 帽函数支撑 (t_{p−1}, t_{p+1}) 与 S 中任一段相交的节点, 再并入其左右相邻节点
            N 中尚未到 cap 的节点各升一级; 若没有可升节点则 break
    u_prev ← u
    重跑 A: 从 u_prev 出发跑完整三阶段 h=[20,60,T−10]
    重跑 B: 从 u_prev 出发只跑最后一阶段 h=T−10
    候选 = {u_prev} ∪ {本轮各阶段可行终点};  u ← 候选中全长目标 J 最大者
输出: u, 轮次, 最终 m, 每轮的 J/驻留/运行时间
```

规定：

- 候选**显式包含上一轮的解** `u_prev`，所以 J 不会因数值优化走差而下降。
- 选候选只用全长目标 J；**不用观测谱峰、不用 η、不在多个半径的结果之间挑选**。
- local 模式最多两轮扩张，与 global(cap 0.08) 相同。
- 第 0 轮之后不触发时，ADA 输出与固定 0.02 逐位相同（G4）。
- 只要逐条结果与上述定义完全一致，可以用等价的高效实现（例如 global 模式下各级解与 τ 无关，可先算好各级解再按 τ 套规则）。

### 2.9 指标与统计

**仿真逐记录指标**（沿用 E4a `measure`，推广到 T）：纯目标 η（残余频带内最大）、观测谱峰（dB）、突出度（相对 ±[4,8] Hz 边带中位数）、3 dB 宽度、轨迹 RMSE、最大偏差、超出 0.02 Hz 的最长时长；另记求解器状态、各阶段迭代次数与预算触顶、运行时间（前端、VIT、族、SMR、BTA 各级分别计时）、最终系数、扩张轮次、驻留时长。

**汇总单位**：一个单元 = scene × SNR（× T 或前端）。“合并值”= 各单元均值的等权平均。

**伤害**（冻结）：一条记录 `η_method < η_F02 − 0.01` 记为一次实质退化，F02 为同记录上的固定 0.02。伤害率 H = 各单元退化比例的等权平均。另报告相对 SMR 起点的退化率（`η_method < η_SMR − 0.01`）。

**置信区间**：

- 单元内：对记录做配对 bootstrap，2000 次，2.5/97.5 百分位。
- 合并值：由于同一种子出现在 7 个 SNR 单元中，按**种子成簇** bootstrap：每个场景内有放回抽取种子，携带其全部 SNR 记录，重算各单元均值再等权平均。2000 次。

- 只报告结果方向与区间，不做联合多重比较校正，也不把单元计数写成显著性。

### 3.1 记录

### 3.2 配置

对每条记录、每个 Δ ∈ {60, 30, 20, 15, 10, 7.5, 6} s（P = 6, 11, 16, 21, 31, 41, 51）：

- **主臂（缩放正则）**：SMR(Δ) → BTA 固定 0.02 (F02)；SMR(Δ) → BTA 去盒界 (UNB)。SMR 与 BTA 共用同一 Δ 的族。

VIT 锚轨迹与 Δ 无关，记录其 η 作为共同基线 η_V。

### 3.3 报告

各 Δ 的合并 η、观测谱峰、增益（相对 η_V、相对 SMR(Δ)）、伤害率、BTA 中位运行时间、预算触顶率，分场景给出。图：横轴 P（或 Δ），纵轴 η 与运行时间，F02、UNB、对照臂三条曲线；观测谱峰另图。

### 3.4 Δ* 选择规则

对每个场景 s ∈ {S0, S2}、模式 m ∈ {F02, UNB}（主臂）：

```
G_{s,m}(Δ) = 该场景 7 个单元的 mean(η_BTA(Δ) − η_V) 等权平均
Gmax_{s,m} = max_Δ G_{s,m}(Δ)
Δ 在 (s,m) 下合格 ⇔ G_{s,m}(Δ) ≥ 0.95 · Gmax_{s,m}
Δ* = 在全部 4 个 (s,m) 下都合格的 Δ 中最大的一个（节点最少）
```

按 η 选，不按观测谱峰选（观测谱峰会奖励拟合噪声的自由度）。

结果解读（只用于写作，不改 Δ*）：

- 两种模式都在 P ≤ 21 进入平台：21 节点有直接依据；
- UNB 继续上升而 F02 已平：限制主要来自半径，而非节点数；
- 对照臂与主臂的 Δ* 不同：如实报告“节点数结论依赖正则缩放”，Δ* 仍按主臂。

Δ* ≠ 15 时，后续全部阶段使用 Δ*；E4a 作为旧配置结果保留。

### 4.4 冻结规则（按顺序执行）

记 `G_X` = 合并 `mean(η_X − η_F02)`，`H_X` = 变体 X 的伤害率，`U = G_UNB`。

1. **盒界是否构成限制**：若合并 U < 0.005，固定 0.02 不构成实质限制。冻结 **F02**，确认阶段只比较 F02 与 UNB（分支 C0），跳过下列 2–4。
2. **重跑方式**：对 D2a 中被触发的记录，若
   `mean|η_B − η_A| < 0.005`、`mean|peak_B − peak_A| < 0.1 dB`，且 `median(runtime_B / runtime_A) < 0.6`，
   冻结 **B**；否则冻结 **A**。
3. **自适应参数**：在 D2b 的 20 个变体中，合格条件为 `G ≥ 0.9·U`。在合格变体中取 H 最小值 H_min；在 `H ≤ H_min + 0.005` 的变体中依次优先：global 优先于 local → cap 0.04 优先于 0.08 → τ 较大者。没有合格变体时，取 G 最大的变体，并在报告中注明“未保留去盒界 90% 的增益”。
4. **固定半径是否已经够用**：若某个固定半径 ρ ∈ {0.04, 0.08} 在 **S0 和 S2 两个场景分别**满足
   `G_ρ ≥ G_ADA − 0.002` 且 `H_ρ ≤ H_ADA + 0.01`，
   则冻结满足条件的最小 ρ（分支 C-F），不采用自适应扩张。否则冻结第 3 步选出的 ADA（分支 C-A）。

此外记录“最佳固定半径” F* = ρ ∈ {0.04, 0.08} 中合并 G 最大者，作为确认阶段的对照。

### 6.2 方法（同一批记录）

### 6.3 终点

| 编号 | 内容 | 判定 |
|---|---|---|
| P1 | FM − F02 的合并 Δη | 种子成簇 95% CI 下界 > 0；另分场景报告 |
| P2 | FM − UNB 的合并 Δη（非劣） | 95% CI 下界 > −0.005 |
| P3 | 伤害率之差 H_FM − H_UNB | 成簇 bootstrap 95% CI 上界 < 0 |
| S1 | 单元层面无系统性退化 | 不存在 FM − F02 单元均值 Δη 的 95% CI 上界 < −0.005 的单元 |

**不要求** FM − F02 在每个单元的 CI 都为正（不需要扩张的记录上 FM 本就等于 F02）。

次要终点：观测谱峰、突出度、3 dB 宽度、轨迹 RMSE、最大偏差、扩张比例与轮次、运行时间。论文主结果另报告 **FM − SMR** 的逐单元配对增量（与 E4a 表格同口径：均值、中位数、IQR、95% CI、正值比例）。

### 6.4 分支

| 分支 | 条件 | 论文中的方法 |
|---|---|---|
| C-A1 | P1、P2、P3、S1 全部满足 | 自适应扩张为主方法 |
| C-A2 | P1、P3、S1 满足，P2 不满足 | 自适应仍为主方法，正文写明与去盒界的取舍：平均 η 低多少、退化少多少 |
| C-A3 | P1 不满足 | 主方法保持固定 0.02；去盒界与半径结果作为敏感性分析 |
| C-A4 | P1 满足但 S1 不满足 | 主方法保持固定 0.02；自适应作为变体报告，并列出退化单元 |
| C-F | 冻结的是固定半径 ρ | 同样按 P1–P3、S1 判定，ρ 取代 0.02 的条件同 C-A1/C-A2 |
| C0 | D2 第 1 步已判定盒界不构成限制 | 主方法为固定 0.02 |

结果落在两个分支之间时，如实写“介于两者之间”，不归到较近的一支。确认阶段之后方法**不再修改**，X 阶段一律使用分支所定的方法（下称“最终方法”）。

## 10. X3：多线谱实测

### 10.1 候选频点（运行前写定）

SWellEx-96 S5 发射频点中 49–145 Hz 的全部 33 个：

| 组 | 源级 | 频点 (Hz) |
|---|---|---|
| 深源 Set 1 | 158 dB | 49 64 79 94 112 130 |
| 深源 Set 2 | 132 dB | 52 67 82 97 115 133 |
| 深源 Set 3 | 128 dB | 55 70 85 100 118 136 |
| 深源 Set 4 | 124 dB | 58 73 88 103 121 139 |
| 深源 Set 5 | 120 dB（推断值） | 61 76 91 106 124 142 |
| 浅源 | 未公布 | 109 127 145 |

分组（按官方源级，运行前写定）：**弱线组** = Set 2–5；**强线组** = Set 1；**浅源组** = 浅源三条，单独报告。论文实测主结论以弱线组为准。

时段：10 个不重叠的 300 s 段 `[0,300), …, [2700,3000)`。

### 10.2 可见性筛选（与 Phase A A3 判据相同）

对每个频点，以该频点为中心提取 ±10 Hz、20 Hz 复基带（`phaseA_load_baseband`，守护段 10 s，记录两端不足时取 0），计算 LOFAR（Hann，L=200，D=20，NFFT=8192）。对每个时段：

- `peak_excess_dB` = 频点 ±0.5 Hz 内最大值 − [1, 2] Hz 环带中位数（两侧）
- `ridge_continuity` = 各帧在 ±0.5 Hz 内的峰值频率落在该段峰值频率中位数 ±0.2 Hz 内的帧比例
- **通过**：`peak_excess_dB > 10` 且 `ridge_continuity > 0.6`

该判据对频率较高、跨最近通过点的时段偏严（300 s 内多普勒漂移可能超过 ±0.2 Hz），照原样使用。

核对：94/97/100/103/106/109 Hz 的结果与 `phaseA/tables/A3_visibility.csv` 对照（A3 用 100 Hz 中心基带，这里用频点中心基带，数值会有小差别）。通过/不通过若有翻转，如实列出，不调整判据。

**全部通过的“频点 × 时段”构成实测测试集**，筛选过程不看任何 BTA 结果。已知 103 Hz 900–1200 s 有一条约 0.15 Hz 外的竞争脊（A9），保留在表中并标注，不作为主图案例。

### 10.3 处理

每个通过的案例：窗口 `[s, s+300)`，中心为该频点，候选频带 ±1.5 Hz，评价区间 [5, 295) s，噪声边带 ±[4, 8] Hz，前端参数与 Phase B 相同。

- VS → 最终方法；VS → F02；VS → UNB
- MFT → 最终方法；SUV（`band_hz` 设为 ±1.5 Hz）→ 最终方法
- 指标沿用 `run_B1_realtone.m` 的 `spectrum_metrics`：相对周期图峰值的谱峰、突出度（偏离峰 0.5–1.5 Hz 的中位数为底）、3 dB 宽度；另记扩张轮次、驻留时长、运行时间
- GPS 参考：`f_gps(t) = f_tone · f_gps_100(t)/100`（`phaseA/tables/A4_groundtruth.csv`），只报告各轨迹与它的平均偏移和去均值 RMS，**不用于筛选**（例如 100 Hz 轨迹与参考有 +0.084 Hz 的整体偏移，A8 斜率比检验也未通过）。

### 10.4 实测时长

弱线组中有 ≥2 个连续通过时段的频点：从该连续段起点 s 取嵌套窗口 `[s, s+T)`，T ∈ {150, 300, 450, 600} s（不超出连续通过区间）；Δ = Δ*，P = T/Δ* + 1，阶段块长 `[20, 60, T−10]`。方法：VS → 最终方法、VS → F02。100 Hz 若 900–1200 与 1200–1500 两段都通过，即覆盖原 900–1500 s 案例，并以新配置取代原 600 s 结果（原结果是 21 节点、30 s 间隔、末阶段 290 s 块）。

### 10.5 统计与主图

- 逐案例配对增量（最终方法 − SMR；最终方法 − MFT；MFT 接模块前后；SUV 接模块前后）。
- 各组汇总：中位数、IQR、正值个数/总数。案例共享航次与时间，不做显著性检验。
- 主图角色（运行前写定，以 BTA 之前即可确定的属性定义）：(a) 弱线组中 `peak_excess_dB` 最低的通过案例；(b) 弱线组中连续通过时段最长的频点（LOFAR 叠加轨迹 + 时长曲线）；(c) 与 (a) 同时段的强线组频点作对照（若该时段有强线通过）。同一角色有多个候选时可选最清楚的一个，图注写明选择方式；全部案例进补充表。
