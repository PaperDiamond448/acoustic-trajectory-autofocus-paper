# Phase D 开发图形约定

绘图后端沿用已保存的 Python 偏好；实验计算在 MATLAB R2023a 中完成。

D1 的科学问题是：在何种节点数下，两个场景与两种盒界模式的纯目标 η 收益进入平台，计算代价如何改变？上排给 η 与成簇 95% 区间，下排给描述性时间中位数；观测峰值另图，仅作诊断，不参与选 Δ。所有七个间隔和全部 840 条记录保留。

D2 的科学问题是：扩大修正半径能否保留收益，同时控制相对 F02 的退化？按场景给配对 η 增益与伤害率，固定半径和去盒界完整显示，叠加开发规则选出的 ADA 及区间。最终方法的冻结来自表中逐条规则，不由图形观感决定。

类型：quantitative grid。双栏宽约 183 mm，所有字体至少 5 pt；固定方法配色跨图保持一致。区间均使用场景内种子成簇重采样、携带全部七个 SNR，2000 次，seed=20261051；时间中位数只作描述，不画推断区间。开发集结论不能写作独立确认。

导出 PNG/PDF/SVG，保留可编辑文字与 source data。每张多面板图导出前进行 1.5 pt 面板对齐审计，最终 PDF 做文字字号和碰撞审计，再目视核验每个面板。任何绘图修复只影响显示，不能改变实验输入或冻结规则。
