# X 科研图约定（统计结果可用之前写定）

延续已更新的 Nature Figure 2.8.0、Python 后端；只复用本项目既有图的字型、配色与静态导出，不借用旧数值。

X1 问题：冻结方法的增益与时间成本如何随积累时长变化？2×2 面板，列为 S0/S2；上排 SMR/F02/UNB/ADA 的纯目标 η（均值及场景内种子成簇 95% CI），下排 F02/UNB/ADA 受六工人并行负载影响的单次调用墙钟中位数及 p90。所有 4 个 T 与 3 个 SNR 单元等权，无门槛。计时图明确不是串行性能基准。

X2 问题：在不同入口质量下，模块还能回收多少相干效率？两个横排面板，入口 η 的十个固定 0.1 箱；左 Δη，右 (η_out−η_in)/(1−η_in)，右只纳入 η_in<.95。四个前端同轴，保留负值和空箱断点，样本数另表。此图为描述性分箱均值，统计区间另见合并表，不虚构独立样本误差条。

X3 主图：弱线最难可见案例与同时段强线的无平滑公共谱（角色 a/c），对照 Periodogram、SMR、F02、VS ADA。第二图：最长连续可见弱线（角色 b）的原始 LOFAR 与 GPS/SMR/ADA 轨迹，另一面板为嵌套时长谱峰增量（所有冻结弱线连续段另外完整作图/表）。角色仅依据筛选而定，不因输出更好而换案例。全部 106 案例与全部时长进入表。

实测汇总图：强、弱、浅三组分别显示全部 VS ADA−SMR 谱峰增量，包含负值，以中位数/IQR 辅助，不作显著性检验。Set 5 推断源级在图注标明。

统一宽 7.2 inch（约 183 mm）、文字至少 7 pt，颜色兼用方法标签和线型；PNG 600 dpi、PDF/SVG，源检查、PDF 字型检查、面板对齐与碰撞检查及逐图最终像素视觉检查。每图附数据表、图注、QA 与指纹。
