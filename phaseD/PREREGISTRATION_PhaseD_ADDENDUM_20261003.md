## A1. Δ* 的可冻结集合（取代主方案 §3.4 中“Δ* = …最大的一个”的取值范围）

D1 仍扫描全部七个间隔 {60, 30, 20, 15, 10, 7.5, 6} s，并报告全部曲线。**最终可冻结的 Δ* 只能取自**

```
F = {30, 15, 10, 7.5, 6} s
```

原因：X1 与 X3 的时长 T ∈ {150, 300, 450, 600} s 要求节点 `0:Δ:T` 落到 T 上、`P = T/Δ + 1` 为整数，而 60 s 与 20 s 不能整除 150 s 与 450 s。60 s 与 20 s 只作趋势诊断。

## A2. Δ* 规则的边界情况（补充主方案 §3.4）

对每个 (s, m) ∈ {S0, S2} × {F02, UNB}，`G_{s,m}(Δ)` 定义不变，`Gmax_{s,m}` 在**全部七个** Δ 上取最大值。

1. 合格判定：
   - 若 `Gmax_{s,m} > 0`：Δ 合格 ⇔ `G_{s,m}(Δ) ≥ 0.95 · Gmax_{s,m}`（与主方案相同）；
   - 若 `Gmax_{s,m} ≤ 0`：Δ 合格 ⇔ `G_{s,m}(Δ) ≥ Gmax_{s,m} − 0.005`。
2. `Δ*` = F 中在全部 4 个 (s, m) 下都合格的 Δ 里最大的一个。
3. 若该交集为空：对 F 中每个 Δ 计算最坏绝对差距 `W(Δ) = max_{s,m} [Gmax_{s,m} − G_{s,m}(Δ)]`，取 W 最小的 Δ；W 相差不超过 1e-4 时取较大的 Δ。报告中注明“95% 规则无解，按最坏差距选取”。

用绝对差距而不用比例，是为了在 Gmax 接近 0 或为负时仍有定义。

## A3. 扩张是否有实质收益（取代主方案 §4.4 第 1 步）

记 `G_X^s` 为场景 s 内 `mean(η_X − η_F02)` 的 7 单元等权平均。

- **只有当** F04、F08、UNB 在 **S0 与 S2 两个场景中**都满足 `G_X^s < 0.005` 时，才判定扩大修正域没有实质收益，冻结 F02（分支 C0）。
- 否则进入第 2–4 步。

理由：UNB 无明显收益并不意味着 F04/F08 也没有；有限扩张优于完全放开，本身就是需要看到的结果。

## A4. 自适应参数的参照增益（修改主方案 §4.4 第 3 步的合格条件）

主方案第 3 步以去盒界增益 U 为参照。按 A3 的同一理由，参照改为**所有扩张方式中最好的合并增益**：

```
Gref = max(G_F04, G_F08, G_UNB)        （合并值，7×2 单元等权）
合格 ⇔ G_ADA ≥ 0.9 · Gref
```

其余（H_min、近似并列时的优先顺序、无合格变体时的处理、第 4 步固定半径检验、F* 的定义）不变。确认阶段 P2 仍对 UNB 做非劣检验；F* 一并报告，作为次要对照。
