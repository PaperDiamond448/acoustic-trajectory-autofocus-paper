## 2 三个结论

**(1) "面向功率型前端"有了普遍性。** 文献 [12] 的动态参数 HMM 接上模块后提高 0.32。无干扰、DHMM 与 PC-TBD 都跟住的 637 条记录上，DHMM 加模块为 0.918，PC-TBD 为 0.897。分信噪比看，−16 dB 时 0.930 对 0.892，−14 dB 时 0.969 对 0.944。

**(2) PC-TBD 的强度来自相位差读出。** 按原文用状态网格读出时，PC-TBD 的 η 只有 0.296，接上模块提高 0.43；换成本文的相位差读出后，模块几乎没有增益。读出与模块做的是同一件事：用相位信息确定频率。这是"缓变误差要靠相位信息消除"最直接的证据。两个版本都要在论文中报告。

**(3) 两条路线最终停在同一水平。** 取无干扰、两者都跟住、PC-TBD 没有整周错误段、σ² < 5 的记录：VIT–LPS 从 0.838 修正到 0.948，PC-TBD 输入为 0.944，修正后同样是 0.948。修正后残余相位方差的频带分布也几乎一样：周期长于 60 s 的中位数为 0.012 对 0.012（VIT–LPS 修正前为 0.040），20–60 s 为 0.017 对 0.018。功率型前端加模块，与相位型跟踪器在这种条件下等效，连残余误差的结构都相同。

## 3 修正上一轮的一个说法

上一轮我推断"PC-TBD 输入时已经在噪声平台上"。真值起点的结果表明这个说法太强，需要改为：

- 有噪声时，从真值出发修正后为 0.963（无干扰、两者都跟住的记录上为 0.972）。这是噪声本身造成的损失，也是两条路线都达不到的参照。
- 从有误差的轨迹出发，两条路线都停在约 0.95；20–60 s 的残余分量，带噪声的目标函数分辨不出来。
- PC-TBD 的额外损失集中在含整周错误段的记录：无干扰、两者都跟住时，含这类段的 57 条记录上 PC-TBD 为 0.715，VIT–LPS 加模块为 0.806，真值起点为 0.952；模块修不了这种台阶。
- 局部干扰下，两者都跟住时真值起点为 0.971，VIT–LPS 加模块和 PC-TBD 分别只有 0.732 和 0.752。差距来自前端在干扰期间跟随干扰线，而不是噪声。这是两种方法共同的局限，可以写进讨论，作为后续方向。

## 4 对论文的影响

跨前端部分现在可以这样写：

1. 模块接在三种功率型前端之后（VIT、MFT、DHMM），都有显著增益，并且增益由理论（无噪声可达值）预测；
2. PC-TBD 两种读出的对照，说明相位信息才是关键；
3. 在跟住、无突发误差的条件下，两条路线收敛到同一水平，残余误差结构相同；
4. 真值起点给出噪声决定的参照；局部干扰是两者共同的短板。

PC-TBD 由此从"需要辩护的反例"变成"支撑核心论点的对照"。
