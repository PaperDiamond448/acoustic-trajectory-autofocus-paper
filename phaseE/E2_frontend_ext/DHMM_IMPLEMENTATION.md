# 动态参数HMM：单线谱实现与原文对照

来源：罗昕炜、李磊、沈子涵，基于动态参数HMM的水声信号线谱轨迹提取方法，电子与信息学报44(6)，1956–1965（2022），DOI 10.11999/JEIT211374。原PDF在精选文件夹06文献目录。

| 环节 | 本次实现 | 与原文关系 |
|---|---|---|
| 初始状态 | 均匀 | 同式(3) |
| 一维频率状态 | VIT的0.005 Hz粗网格、10 s Hann/1 s帧移 | 本文改编，与现有前端共用观测 |
| 观测得分 | log(1+归一化功率) | 本文改编，沿用VIT得分；原文式(5)为归一化幅值 |
| 动态转移 | 对每个存活状态分别回溯L1帧，用最小二乘估计状态斜率；高斯核中心移至j+斜率，逐源状态归一化 | 同式(9)、(10)、(13)、(18)的动态斜率更新 |
| 数值转移核 | σ=1个本次状态步长；围绕四舍五入的斜率中心截断G个步长 | 沿用原文σ数值1，网格单位与有限截断为本文具体实现，未把其称为原文1 Hz设置 |
| 递推与回溯 | 对数域Viterbi，概率为零的状态不参与最优路径 | 同式(15)–(19)，对数域为数值实现 |
| 多线循环、生灭、块融合 | 单线持续目标，不运行这些环节 | 本文改编，按任务书限定 |
| 输出平滑/插值 | 5帧中值滤波，线性插值、端点常值 | 本文改编，与现有VIT输出一致 |

原文未指定的L1和G在新的phase56开发集选择，共S0/S2×3个SNR×20=120个输入、9组候选。指标为前端自身η中位数；没有用接模块后的增益选参数。开发记录和汇总保留；选定参数在DHMM_FROZEN.json，之后不能据B/C/D结果修改。

当前选定L1=10帧，G=3个步长，σ=1个状态步长，输出中值窗5帧。开发η中位数0.3231099958。这是参数选择结果；正式同记录比较由完整任务B给出。
