# 在线分析与绘图的路径适配

当前修订图程序、中文图程序和谱峰归属分析，现从仓库自己的位置寻找 `phaseD/` 与图表输入，无须把仓库固定放在原电脑的 D 盘路径。

适配仅修改读写路径；数学计算、筛选规则、分组、统计量和已保存图件没有改动。路径适配的原始与当前校验值记在 `整理清单.csv`，冻结 MATLAB 核心没有改动。

Nature Figure 的面板对齐检查函数随图程序收录，保留原字节。Windows 字体只在字体文件存在时注册；中文重绘环境仍需要可用的中文字体，浏览现有 PNG/PDF 不需要字体安装。

## 使用

- 在线读完整稿：打开根目录 `在线阅读_完整修订稿.md`。
- 修改章节后更新合并稿：`python tools/update_reading_copy.py`。
- 复核补充实测归属：运行完整修订稿 `补充分析_实测峰归属/peak_attribution.py`，默认读取同目录保存的 `baseband/`。
- 修改修订图：完整修订稿 `_build/figs/render_revised.py` 读取保存的结果及时频缓存。绘图与分析会写自己的输出，运行前在新分支中工作，保留现有图作为对照。

旧实验驱动、完整 MATLAB 复跑和原执行审计脚本仍记录原 Windows 环境；云端环境没有 MATLAB 时使用保存的 CSV、谱、轨迹和 Python 分析，不启动新实验。
