# E0 相位口径修复与复核

日期：2026-09-25；MATLAB R2023a。范围仅限 E0 数值核查与修复；不重跑 A7–A10，不改 BTA，不启动 Phase C。旧 E0 文件保留为历史结果，新输出使用 `E0_phase_corrected_*` 文件名。

## 结论

原 E0 的相干效率调用把补偿轨迹、频率误差和零轨迹混为一谈，导致三个指标标签实际对错：原 `eta_none` 使用真值轨迹，实际算的是 oracle；原 `eta_oracle` 使用零轨迹，实际算的是未补偿；原 `eta_full` 把残差 `e=gtrue−ghat` 当作补偿轨迹。慢/快修正也把“剩余误差分量”直接当作补偿轨迹传入，符号和含义不一致。因此，原 E0 中所有依赖 η 的统计、代表记录及图不能用于机理论证。

原 E0 还在完整 0–300 s 上求 η；本次按 `mft_config` / `evaluate_record` 的 `[5,295)` s 评价窗统一计算。指标对照中修复前数值来自全段旧口径，修复后数值来自协议评价窗，不能把两列视作只改变相位项的逐数值比较。

修复后，单记录等价性检查通过，400 条冻结种子均完成回放。频率误差与慢/快分解逐条重现原表，检查字段的最大数值绝对差为 4.22×10⁻¹⁵（频率项单位 Hz，比例项无量纲）。新 η 使用同一目标分量、同一 `[5,295)` s 区间、同一 65536 点 FFT、±2 Hz 残余频率搜索和 `(sum |s|)^2` 归一化。400 条仿真的 oracle η 均约为 1；没有任何估计器 η 超过 oracle。

更正后的 E0 不支持 MFT 与 VIT 之间存在 RMSE/η 排序反转：SIM 与 SIM-S2 均为 0/200。VIT 的平均 RMSE 明显低于 MFT，η 也明显更高，但两者误差量级并不接近。慢误差比例确实是 VIT 高于 MFT；分量修正效果则依估计器而异。故本轮 E0 不能证明“频率 RMSE 较小的方法反而有较低相干效率”在这些实际估计器中出现，也不能据此否定 BTA 的独立真实数据聚焦增益。

## 发现与定义修复

目标生成模型为 `s_target(t)=A a(t) exp(j phi_g(t))`，`gtrue` 是该复基带相位相对参考频率的瞬时频率偏移，单位 Hz。估计器输出 `ghat` 同样是用于补偿的完整频率偏移轨迹。原工程 `evaluate_record.m` 的补偿定义为：

\[
z(t)=s_{target}(t)\exp\left[-j2\pi\int_0^t \hat g(\tau)d\tau\right].
\]

令 `e=gtrue−ghat`。若先用 `gtrue` 去掉真值相位，则必须再乘 `exp(+j2π∫e)`，才与直接使用 `ghat` 补偿等价。误差轨迹本身不能直接传给按 `ghat` 定义的补偿函数。

| 指标 | 修复后的补偿轨迹 |
|---|---|
| 未补偿 | `ghat=0` |
| 前端完整补偿 | `ghat` |
| 慢误差修正 | `ghat + e_slow`，留下 `mean(e)+e_fast` |
| 快误差修正 | `ghat + e_fast`，留下 `mean(e)+e_slow` |
| 理想真值补偿 | `gtrue` |

误差拆分沿用原定义：先从 `e` 中减去其全记录均值，再用原 4 阶低通得到 60 s 慢分量；快分量为去均值误差减慢分量。因此分量修正不消除平均频偏。原慢误差比例继续按 0–300 s 全记录计算以与冻结逐记录表一致；凡与 η 做相关比较的总 RMSE、慢 RMS、快 RMS 均统一在工程配置的 `[5,295)` s 窗口重新计算。相干效率的 FFT 设置为 `Ne=5800`、`nfft=65536`、搜索 `|nu|≤2 Hz`。

跨两场景配对的 MFT−VIT 差异：RMSE（5–295 s）为 +0.7643 Hz（95% 记录级 bootstrap CI [0.7565, 0.7728]，配对符号翻转 p=0.00050）；η_full 为 −0.4238（CI [−0.4403, −0.4078]，p=0.00050）；T=60 s 慢误差比例为 −0.4045（CI [−0.4214, −0.3867]，p=0.00050）。负的慢误差比例差表示 VIT 慢误差比例更高，方向与原报告摘要中的口头误读相反，但与逐记录数据一致。

保留原排序反转判据：要求频率 RMSE 差绝对值大于 0.0005 Hz、η 差绝对值大于 0.02，并且“较低 RMSE 对应较低 η”。修复后 SIM 为 0/200，SIM-S2 为 0/200；两组所有记录均达到差异阈值，分母不是零。也就是说，本批记录中较差 RMSE 的 MFT 同时有较低聚焦 η，没有出现排序反转。旧 η 所选记录 38 已在单记录审计中复核；修复后的判据没有可报告的排序反转代表记录。

## RMSE、慢/快误差与 η 的关联边界

把两种估计器的 800 行合并后，并将 RMSE 与慢/快 RMS 都限制在相同的 `[5,295)` s 窗口，Pearson 相关为：T=60 s 慢误差 RMS 与 η 为 −0.8352（95% 记录级 bootstrap CI [−0.8479, −0.8235]）；评价区间 RMSE 与 η 为 −0.8674（[−0.8799, −0.8560]）；快误差 RMS 与 η 为 −0.8603（[−0.8734, −0.8484]）。合并数据中总 RMSE 与 η 的绝对相关强于慢误差 RMS；差值 `|r_slow|−|r_RMSE|=−0.0322`（CI [−0.0389, −0.0258]）。Spearman 结果也显示总 RMSE 合并相关更强。

但合并相关受到 MFT 与 VIT 之间巨大误差水平差异影响，不能单独作机制证据。分层后相关强弱并不一致：SIM/MFT 中 RMSE 与 η 的绝对 Pearson 相关为 0.399，慢误差为 0.198；SIM/VIT 中分别为 0.482 与 0.516；SIM-S2/MFT 为 0.437 与 0.196；SIM-S2/VIT 为 0.204 与 0.162。因而不能概括为慢误差在每种前端和场景中都比总 RMSE 更能预测 η。

“加回慢/快分量”的效应也因估计器不同：η_slowfix−η_fastfix 在 SIM/MFT 为 −0.0130（95% CI [−0.0144,−0.0116]），SIM-S2/MFT 为 −0.0110（[−0.0124,−0.0097]）；在 SIM/VIT 为 +0.3761（[0.3515,0.3993]），SIM-S2/VIT 为 +0.3906（[0.3746,0.4071]）。正值表示修正慢误差带来的 η 高于修正快误差。方向与误差组成比例相符，但依赖估计器，不能支持单一普适的慢/快因果断言。以上均为同一信号模型下的仿真诊断。

## REAL 部分及研究含义

原 `E0_REAL_reference_only.csv` 的 31 个窗口及其直接 MFT/VIT 频谱峰结果没有修改或重算。它们来自连续 600–1800 s 提取的 31 个相互重叠 300 s 窗，间隔 30 s、重叠 270 s，因此只作描述性对照。A4 推算轨迹仍是参考，不是真实接收相位真值；本次不构造 REAL oracle η。

本次修复后，E0 实际估计器统计不支持“RMSE 排序反转常见”，也不支持把慢误差作为所有方法中的普适主导因素。它支持 VIT 在这组配置中慢误差比例高于 MFT；MFT 与 VIT 在 RMSE、η 量级上差异很大。此前构造误差例子仍可表达数学上的可能性，但不能替代估计器实测。Phase B 的真实线谱直接谱峰结果是另一条证据链，不因本次 E0 η 修复而改变。
