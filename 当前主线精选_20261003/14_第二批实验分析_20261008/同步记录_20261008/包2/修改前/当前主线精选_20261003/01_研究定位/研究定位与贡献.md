## 1. 要解决的问题

弱运动线谱做长时相干积累时，需要一个在整段记录上跟随接收相位的补偿相位。通常先由前端估计一条频率轨迹，再把轨迹积分成补偿相位，补偿后做 FFT。

问题在于，前端用来确定轨迹的准则（逐帧匹配功率、Viterbi 路径概率、平滑惩罚）和长时积累真正关心的输出（补偿后整段记录的相干和）并不一致。频率误差经时间积分变成残余相位：幅值很小但长时间同号的误差会累积成大的相位漂移，快速正负交替的误差反而相互抵消。所以一条已经能跟住目标的轨迹，仍可能留下使积累增益明显下降的残余相位。

**本文的问题**：在已有粗轨迹之后、相位补偿之前，能否直接以补偿后记录的相干输出为目标，在粗轨迹附近修正轨迹？这一步能额外回收多少积累增益？在什么条件下有效？

## 2. 主线与方法一句话

主线：**已有粗频率轨迹 → 相干驱动的频率轨迹自聚焦 → 相位补偿 → 长时相干积累。**

方法：在锚轨迹附近，用固定节点的分段线性频率残差表示修正；修正经积分得到关于系数仿射的补偿相位；以补偿后记录的分块相干能量为目标，用解析梯度和块长由短到长的分阶段 SQP 求解；输出仍是一条轨迹，后面的相位补偿与 FFT 不变，所以可以接在不同前端之后。

最终实现（Phase D 确认）：VIT 给锚轨迹，SMR 给起点，节点间隔 10 s（300 s 记录 31 个节点），修正先限定在 ±0.02 Hz；解在某段时间持续顶边（最长驻留 ≥ 30 s）时，只把驻留段对应帽函数支撑节点及相邻节点放宽到 ±0.04 Hz 再求解一次。旧实现（21 节点、固定 ±0.02 Hz）的结果作为对照保留。见 [08_PhaseD补充实验](../08_PhaseD补充实验/README.md)。

工作标题：*Coherence-Driven Frequency-Trajectory Autofocus for Long-Time Coherent Integration of Weak Moving Tonals*（面向弱运动线谱长时相干积累的相干驱动频率轨迹自聚焦）。用 frequency-trajectory 区分 SAR/SAS 文献中的平台运动轨迹。

## 3. 已有工作做到了哪里

详细对照见 [近邻文献对照](近邻文献对照.md)。要点：

- **轨迹 → 积分相位 → 全长 FFT** 这条处理链本身已有（MFT-LTCIE）。本文加的是这条链中间的一步修正。
- **参数化补偿**（多项式相位、Radon 类、时间扭曲算子库、Doppler-warping 速度搜索）在运动参数或算子空间里搜索，不以外部轨迹为输入。
- **跟踪时利用相位**（幅相联合 HMM、相位连续 TBD、多帧相干 TBD）已经把相干信息放进前端。不能把前端一概说成“只看功率”或“只追求 RMSE”。
- **粗估计后精修**（O'Shea 多项式相位精修、准最大似然选优）、**样条瞬时频率积分为相位**（SEECR）都已存在。
- **以聚焦质量为准则、低维修正 + 平滑先验 + 梯度求解**的结构，在成像自聚焦中已经成形：Fortune 等（SAS，路径低维基 + 对比度 + 高斯路径先验）、Ran 等（SAR，DCT 相位误差 + 锐度 + 平滑正则 + 解析梯度 BFGS）。Mergenthaler 等还报告按成像质量调轨迹滤波器优于按 RMSE 调。

因此，“粗估计 + 低维修正 + 聚焦准则 + 正则 + 梯度求解”这一结构不是本文贡献，引言要正面写出这一点。

## 4. 贡献（当前可以写到的范围）

1. **被动线谱长时积累中的一步轨迹修正**：在外部给定的粗轨迹附近，用频率域的有界残差表示修正，经积分映射为补偿相位，以一维复记录的分块相干能量为目标，位于跟踪前端与 FFT 后端之间。与成像自聚焦相比，修正对象是线谱的频率轨迹而不是平台路径，数据是一维长记录。
2. **适合一维长记录的求解实现**：相位关于系数仿射、解析梯度、块长由短到长的分阶段求解、候选保留初值。分块相干目标可以解释为消去块复幅度后的最小二乘。解析梯度、SQP、分阶段思想本身都不是新的。
3. **相同起点下的证据**：同一 SMR 起点下的配对仿真增益、预筛实测候选记录的观测谱峰增量、接在不同前端后的增益，以及适用条件（粗轨迹可用）。

三条应写成一个方法贡献加它的证据，不写成三个“首次”。不加“首次”。

## 5. 不能写的主张

| 不能写 | 原因 |
|---|---|
| 盒约束（固定 ±0.02 Hz）带来普遍性能优势、防止锁噪 | Phase D确认支持有条件的稳健性取舍：有干扰时局部扩张退化较少；无干扰时自适应相对去盒界η低约0.006 |
| ±0.02 Hz 或 21 节点是最优值 | Phase D已选10 s/31节点；达到预定近平台标准，不是全局最优性证明 |
| 实际前端中“RMSE 更小而 η 更低”普遍发生；慢误差普遍主导 | E0 修正版 400 对中未观察到 MFT/VIT 反序；构造例子只说明数学上可能 |
| 每条记录都改善、任意前端都适用 | 粗轨迹失败时没有增益；只在所测条件下成立 |
| 实测 100 Hz 线谱的声源归属已确认，参考轨迹是真值 | A8 斜率比检验未通过；参考轨迹只能图示 |
| 对 B240 或新组合链报告检测率 | 只有原 P60 批次做过独立虚警标定 |
| 300 s 与 600 s 是两次独立试验 | 实测为同记录嵌套窗口；旧600 s还改变节点间隔；最终方法固定10 s间隔、按T缩放节点数和预算 |
| J_h 就是最终检测统计量 | J_h 含正则、在零残余频率处取值；η 和谱峰在残余频带内搜索最大值 |

## 6. Phase D 带来的变化（确认阶段已完成，2026-10-04）

**全部完成（2026-10-04）**：下列四条都已成立——节点间隔改为 10 s、自适应扩张为主方法（证据 #2C）；实测扩展为 105 个预筛案例、弱线 15/15 为正（#19）；跨前端扩展为四种前端（#18）；另增积累时长研究（#17）。


- 自适应已经通过确认：先在±0.02 Hz内修正，持续贴边达到阈值时局部放宽到±0.04 Hz，最多扩张一次。
- 节点间隔已固定10 s，最终方法的正则、预算与全部主结果按冻结配置使用。
- 实测部分从一条 100 Hz 线谱扩展为多频点、多时段，以弱线组为主。
- 跨前端部分扩展为VIT–SMR、VIT直接、MFT和相位连续TBD四种入口。
- 实测弱源组15/15的候选带最大谱峰增量为正，但指定峰的声源身份未全部确认；133 Hz例有最大峰位置转换。不能把它写成15个指定弱目标均已证实聚焦改善。
- 时长优势限于所测设置；局部干扰时宽固定，干扰占比、节点数和求解预算随记录长度变化。详细解释见 `../10_论证骨架/实验设计复核_20261004/实验设计客观评估.md`。
