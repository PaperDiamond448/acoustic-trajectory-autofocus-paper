**仿真基线**：X2 与 B 的无干扰场景（S0），线性插值到 D 的信噪比网格（−20 至 −14 dB，间隔 1 dB），等权平均：

两者都跟住时：VIT–LPS + 模块 0.887，PC-TBD 0.855。

**D 与仿真的三点差别**

1. **噪声。** 真实背景经归一化后，±2 Hz 内平均谱密度与仿真相同，筛选统计量（0.7–1.7 dB）也接近白噪声（中位数 1.13 dB）。但真实噪声在窗内可能不平稳、不服从高斯分布，对前端相当于有效信噪比下降。我按 0.5–1.5 dB 估计。另外，筛选对比注入目标弱 4 dB 以上的未知线谱不敏感，−20、−19 dB 时前端可能被未知分量带走。
2. **GEO 目标**与仿真几何完全相同，可直接对照仿真。
3. **GPS 目标远比仿真平缓。** 按 A4 计算，各 300 s 窗内 GPS 频率曲线的总变化为 7–115 mHz，去线性后的弯曲 7–47 mHz，最大斜率约 0.4 mHz/s；仿真几何是 CPA 通过，总变化约 0.5–0.8 Hz，斜率最大约 1.7 mHz/s。

P3、P6 的理由：误差中慢分量主要由噪声驱动的轨迹漂移造成，但目标越平缓，逐帧取峰与平滑带来的偏差越小，所以 GPS 目标上前端留下的慢误差应更少，模块可回收的部分也更少。这正是理论的预测：增量取决于前端留下的慢误差，而不是固定值。

## 3 结果怎么读

| 结果 | 含义 | 第 5 节怎么写 |
|---|---|---|
| P1、P5 成立，绝对 η 比仿真低不超过 0.1 | 真实噪声下结论不变 | 注入作为第 5 节主证据，仿真结论直接迁移 |
| P1 成立，但 GPS 目标增量很小（< 0.05） | 平缓目标留下的慢误差少，与理论一致 | 按目标类型分别报告，用前端误差谱解释；这是理论预测的检验，不是失败 |
| 某个功率型前端增量的区间含 0 | 真实噪声下修正不稳定 | 查看是哪类误差（突发、丢线），用 A2 分区解释；如果是缓变区间内增量消失，需要重新审视 |
| 真值起点明显低于 0.9 | 真实噪声使目标函数最大值点偏离较大 | 讨论中说明真实噪声下的估计下限，模块与 PC-TBD 同受影响 |
| 跟住率在 −20、−19 dB 远低于仿真 | 未知弱线谱或非平稳噪声带走前端 | 作为捕获问题报告，与模块无关 |
