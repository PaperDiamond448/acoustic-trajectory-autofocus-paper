# 任务 A 结果分析（Claude，2026-10-07）

数据：`phaseE/E1_trajexport/traj_export_X2_theory_metrics.csv`（5600 行）及 X1 四个时长的同名文件。本分析只读这些 CSV，没有改动任何文件。

## 1 结论先行

1. **小误差近似本身很准。** σ² < 0.5 时，四种前端的预测误差为 0.0015–0.0032（Codex 报告）。
2. **增益预测为负的原因：我给的预测量用错了范围，不是理论错了。** `pred_recoverable` 基于未折叠（unwrapped）相位的二次近似。前端误差里有两类东西：连续的缓变小误差，以及突发误差（干扰期间短暂跟随干扰线、MFT 的逐帧野值、可能的 PC-TBD 读出整周错误）。突发误差会造成几十 rad 的相位台阶，而 η 只取决于相位对 2π 取模后的值，二次近似在这里没有意义。
3. **在理论适用的范围内，预测非常好。** 只看输入 σ² < 5 的记录（以连续误差为主），预测量与实际增量的 Spearman 秩相关为：VIT–LPS 0.95、VIT 0.93、MFT 0.72。
4. **模块的主要增益恰好来自理论适用的区间。** 见第 2 节的分区表：VIT–LPS 在 σ² 为 0.5–5 的 115 条记录上，η 从 0.471 提高到 0.854（+0.383），是各区间中最大的。
5. **PC-TBD 的预测在理论适用区间内得到确认。** 无干扰、σ² < 0.5 的记录中，PC-TBD 与 VIT–LPS 去均值后的均方根误差相同（中位数都是 4.7 mHz），但 PC-TBD 的 η 更高（0.957 对 0.925），周期长于 60 s 的相位方差中位数只有后者的三分之一（0.01 对 0.03 rad²）。同样大小的频率误差，PC-TBD 留下的慢误差更少，这正是理论预测的。Codex 报告中"慢分量份额相近"一句用的是全部记录的中位数，被突发误差主导，不能用来比较。

## 3 尚未确认的一点：PC-TBD 的 B 区间

PC-TBD 有 81 条记录 σ² 在 0.5–5 之间，但 η 仍有 0.767（二次近似预测应低于 0.6），模块也只提高 0.009。我的假设是：相位差读出的整周数偶尔判错，造成约 0.125 Hz、持续约 8 s 的频率误差，也就是约 2π 的相位台阶。台阶抬高了未折叠相位的 σ²，但对 η 影响有限，模块的平滑有界修正也修不了它。这一点需要逐条轨迹才能确认，已写进 `diagnostics_A2.py`（`n_slip_runs`）。

## 4 下一步：任务 A2（Codex 在本机运行，不需要 MATLAB）

`diagnostics_A2.py` 对每条（记录，前端）计算：

- **无噪声可达上限**（`eta_clean_m1`、`eta_clean_m2`）：在没有噪声的目标上，用同一锚轨迹、同一修正族（10 s 节点、r = 0.02 Hz、幅度界 ±0.02 或 ±0.04 Hz、式 (15) 的平滑罚、20/60/(T−10) s 分阶段）能达到的 η。实际增量可以拆成"上限减修正前"和"上限减修正后"两部分，前者是修正族和幅度界允许回收的部分，后者是噪声造成的损失。它直接用 η 计算，不依赖二次近似，所以对突发误差同样适用，应能替代 `pred_recoverable` 作为跨前端的增益预测。
- **突发误差指标**：误差超过 20 mHz、50 mHz 的时间比例，以及超过 50 mHz 的最长持续时间。
- **整周错误计数**（`n_slip_runs`）：误差超过 0.0625 Hz、持续 4–12 s 的段数。

这是理想化的上限：全局幅度界代替局部扩张规则，用 L-BFGS-B 代替 SQP，不含频带约束，所以只用于分解和排序，不当作冻结方法的结果。

运行：

    python phaseE/scripts/diagnostics_A2.py phaseE/E1_trajexport/traj_export_X2 6
    python phaseE/scripts/diagnostics_A2.py phaseE/E1_trajexport/traj_export_X1_T300 6   # X1 四个时长同理

X1 的导出里没有 VIT 轨迹，VIT–LPS 只能以自身输入为锚轨迹、从 0 出发，输出中 `anchor_is_input=1`。合成数据自测约 0.16 s/行，X2 全部 5600 行在 6 进程下约几分钟。

## 5 对论文写法的影响

- 理论部分写成：二次近似刻画连续缓变误差造成的损失，并预测模块在这一区间的增益（秩相关 0.93–0.95）；突发误差（跟随干扰、野值、整周错误）造成相位台阶，影响取决于折叠后的相位，超出二次近似，用 η 本身或无噪声上限分析。
- 模块的价值落在 B 区间：前端已跟住、误差为几到十几 mHz 的缓变误差，这正是理论指出的"在逐帧谱上看不见、积分后损失很大"的那一类。
- PC-TBD 的比较改用 A 区间的同均方根误差对比，作为理论预测的直接验证。
