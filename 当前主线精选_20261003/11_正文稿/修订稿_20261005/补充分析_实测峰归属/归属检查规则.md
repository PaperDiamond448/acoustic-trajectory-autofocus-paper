# 实测最大观测谱峰的归属检查：规则（运行前写定）

写定时间：2026-10-05，运行脚本之前。性质：**结果得到后的事后描述性分析**，回应三份审阅共同提出的“实测增强峰与目标线的对应”问题（S-M1 / R1-M2 / R2-M1 / R3-M1）。只读已保存的数据，不重跑任何前端、修正或筛选。

## 输入（均为已保存文件）

- 20 Hz 复基带：`D:\论文集\phaseD\X3_real\screen_inputs\f{频点}_s{起点}.mat`（筛选与实测处理共用的输入；经 MATLAB 只读导出为二进制）。
- 各方法补偿轨迹：`phaseD\X3_real\tracks\f{频点}_s{起点}_T300.csv`（列为名义频点 + g(t)，含 GPS 推算参考）。
- 各方法积累谱：`phaseD\X3_real\spectra\f{频点}_s{起点}_T300.csv`。
- 各方法最大峰频率：`phaseD\X3_real\X3_cases.csv` 的 `peak_frequency_hz`。

## 参照脊线（只用运行修正之前就有的筛选信息）

1. 按筛选时的做法计算整段 0–3000 s 的连续 LOFAR：10 s 对称 Hann 窗、1 s 帧移、8192 点 FFT，各帧按帧中心归属时段。
2. 每帧在名义频点 ±0.5 Hz 内取最大值频率 r_k，这正是筛选判据“脊线连续性”所用的逐帧峰值。
3. 取本时段内满足 |r_k − median(r)| ≤ 0.2 Hz 的帧（筛选计为连续的帧），对时间做三次多项式最小二乘拟合，得到参照脊线 f_ref(t)。报告拟合残差的均方根。

## 最大峰映射回原始频率

方法 M 的补偿轨迹为 f_M(t) = 名义频点 + g_M(t)，最大峰位于残余频率 ν_M = peak_frequency_hz − 名义频点。若该峰来自某一分量，则该分量的频率轨迹近似为 m_M(t) = f_M(t) + ν_M。

## 判定（对 LPS 与完整方法分别判定）

在本时段各帧中心计算 d_k = |m_M(t_k) − f_ref(t_k)|，取中位数 D_M：

- D_M ≤ 0.05 Hz：最大峰对应筛选脊线（0.05 Hz 为 10 s Hann 窗主瓣宽度 0.2 Hz 的四分之一，约为逐帧峰值定位精度的量级）；
- D_M > 0.10 Hz：最大峰不对应筛选脊线；
- 其余：不确定。

## 同一脊线上的峰值比较

对方法 M，参照脊线在其残余谱上的位置为 ν̄_M = mean_k[f_ref(t_k) − f_M(t_k)]。取 |ν − ν̄_M| ≤ 0.10 Hz 内的谱最大值作为该方法在参照脊线上的峰值；两方法之比（dB）为“参照脊线峰值增量”。另报告 0.05 Hz 窗口的结果作敏感性检查。

## 其他输出

- 参照脊线相对 GPS 推算曲线的平均偏移与去均值均方根（只作参考）。
- 完整方法与 LPS 轨迹之差的时间平均（修正中的常值分量）和最大绝对值。
- 每例一张诊断图：±1.5 Hz LOFAR、参照脊线、两种方法的映射轨迹。

## 使用约束

- 15 个弱线组案例全部报告，保留总分母；不以归属结果删改原有统计。
- 结果写入正文时标明为结果得到后的检查；归属判定须由作者看诊断图确认后才作为定论。
- 阈值 0.05/0.10 Hz、窗口 0.10 Hz 在运行前写定，运行后不调整；若需要别的阈值，另行报告并注明。

## 2026-10-06 更正与补充（运行后记录，原规则未改）

- 上文“0.05 Hz 为 10 s Hann 窗主瓣宽度 0.2 Hz 的四分之一”用词有误：200 点对称 Hann 窗在 20 Hz 采样下，主瓣第一零点约在 ±0.20 Hz，零点间全宽约 0.40 Hz。0.2 Hz 是主瓣半宽，0.05 Hz 约为半宽的四分之一。阈值是描述性容差，不是经过校准的定位精度。
- 类别名称改为“与筛选脊线一致 / 不确定 / 不一致”，强调这是映射几何关系的判据，不是声源身份的确认。
- 应审稿复核意见补充（不改变原判据）：逐帧偏差的 90% 分位数与偏差 ≤0.05 Hz 的帧比例（`逐帧偏差统计_15例.csv`）；接受阈值 0.025/0.040/0.050/0.075 Hz 下的满足例数（5/7/8/9）；以脊线位置为中心 ±0.05 与 ±0.10 Hz 两种峰值窗口的增量（已在 `实测峰归属_15例.csv` 的 `gain_ridge_peak_w05_db`、`gain_ridge_peak_db` 列）。
