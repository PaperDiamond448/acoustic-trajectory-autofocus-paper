## 结果

| 链路 | 最大峰位于筛选脊线上 | 不确定 | 不在其上 | 位于脊线上的案例增量 |

- 完整方法“不在脊线上”的 6 例与原稿图 10(a) 的 6 个空心点完全相同：52 Hz 600 s 和 121 Hz 0 s 的轨迹停在频带上沿，133 Hz 1200 s 停在下沿；52 Hz 900 s、103 Hz 1200 s、118 Hz 1500 s 跟随筛选频带外的其他脊线。
- 133 Hz、1200–1500 s：LPS 的最大峰（+1.40 Hz）映射到筛选脊线；完整方法的最大峰（−1.49 Hz，搜索带边缘）映射到约 130.0 Hz，与深源第 1 组 130 Hz 强线频点一致。原稿“峰位转换、零频形成峰”的叙述据此改写。
- 积累时长窗口：100 Hz 两组除 600 s 起的 150 s 窗口外都在脊线上；52 Hz 一组 4 个窗口都不在；103 Hz 一组 450 s 不确定、600 s 不在。

## 需要作者看图确认

1. 103 Hz、900–1200 s：按判据位于筛选脊线上，但这条脊线 300 s 内下降约 0.6 Hz，GPS 推算只变化约 0.1 Hz，可能不是拖曳声源的 103 Hz 线。
2. 121 Hz、0–300 s：筛选脊线（约 120.7 Hz）本身较弱；LPS 的最大峰映射到约 121.25 Hz，与 GPS 推算（约 121.2 Hz）接近。哪一个是目标线需要人工判断。
3. 61 Hz、2100–2400 s 与 136 Hz、900–1200 s：判为在脊线上，但筛选脊线相对 GPS 推算的偏移（−0.21、−0.06 Hz）与 100 Hz 的 +0.08 Hz 不同。
4. 52 Hz、2400–2700 s：偏差 0.07 Hz，判为不确定；脊线在名义频点以上，而该时段声源远离、GPS 推算在名义频点以下。
