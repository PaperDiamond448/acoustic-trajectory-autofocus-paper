# 图 3 示例面板

问题：逐帧看起来较小的频率误差，能否经相干驱动修正恢复目标谱峰？

(a) 同一记录修正前后的频率误差，(b) 同一记录的目标分量补偿谱与理想补偿。该示例为无干扰、−17 dB、未触发扩张的一条确认记录。正式总体证据仍由图 3(c)、(d) 给出。

候选条件、唯一入选记录和数值见所附 CSV、JSON。评价时段为 [5,295) s；三条功率谱均除以同一时段理想补偿的最大目标谱峰，基准为 0 dB。源 CSV 保留 ±0.15 Hz，绘图显示主瓣附近 ±0.02 Hz、−32 至 2 dB。图中文字为英文，供后续整幅图 3 统一编排。未增加实验或改变方法。

采用 Nature Figure 的 Python 工作流，输出 PDF、SVG 与 600 dpi PNG。两面板绘图区尺寸、对齐、PDF 字号及文字碰撞已核查；渲染图已逐面板看过。谱曲线低于显示范围时仅在图中截出视窗，CSV 保留完整值。
