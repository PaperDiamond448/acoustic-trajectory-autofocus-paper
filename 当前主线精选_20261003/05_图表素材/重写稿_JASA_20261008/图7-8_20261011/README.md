# 图 7：真实背景注入；图 8：自然线谱

中文与英文分别保存，彩色 PDF / SVG 为矢量版本，PNG / TIFF 为 600 dpi 导出。图注与第 5 章同步，见《图注_中文.md》。源数据和绘图程序均在本文件夹中。

图 7 使用 18 个背景窗；每类目标、每个信噪比 360 条记录。先求每窗内 20 次注入的均值，再按窗口与频带等权汇总。95% 区间沿用原实验的 2000 次分频带重抽样索引，同一背景窗携带配对方法、目标类型与信噪比。变差定义为 η 降低超过 0.01；两类目标共享 0–40% 的比例坐标，完整显示全部区间。

图 8(a) 使用全部 105 个案例，点的水平偏移只为区分重叠，黑线示中位数和四分位范围。(b) 的 LOFAR 用已保存的 136 Hz 复基带输入，10 s 对称 Hann 窗、1 s 帧移、2048 点展示 FFT；每帧减去名义频点两侧 1–2 Hz 环带的功率 dB 中位数，统一色阶 −5 至 20 dB。显示 135.94–136.34 Hz，以包含估计轨迹与强线参照。

(c) 的基准是同一案例未补偿周期图在完整 ±1.5 Hz 搜索带的最大值，两条谱均使用完整 300 s，图中放大到 ±0.025 Hz。完整频带保留在 CSV。(d) 画 [905,1195) s 优化时段的修正量；最大 28.311 mHz。完整记录的端点延伸使最大修正量达到 33.337 mHz，两者的时段定义分别保留。

136 Hz 相对强线参照的整段中位偏移为 −0.008634 Hz，优化时段中有 65.86% 的样点偏移超过 0.05 Hz。这两种统计量交代的是不同的轨迹性质。图 8 用该例展示谱峰增量与修正形式，强线参照提供位置比较。
