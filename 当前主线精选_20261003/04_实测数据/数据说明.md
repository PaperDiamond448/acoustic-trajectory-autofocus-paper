# 实测数据说明：SWellEx-96 Event S5

更新：2026-10-03。依据：官方说明（`官方元数据/`）、Phase A 报告与 A8–A10 报告（`报告/`）、源级核查记录（`研究工作台/方向二_实测源级发现_20260912.md`）。

## 1. 实验与记录

- **实验**：SWellEx-96，1996 年 5 月，圣迭戈附近浅海。Event S5：R/V Sproul 拖曳声源以约 2.5 m/s（5 节）航行。官方页面：https://swellex96.ucsd.edu/s5.htm
- **声源与发射线谱**：
  - 深源 J-15（约 54 m），T-49-13 线谱组，5 组 × 13 个频点（49–400 Hz），各组源级依次降低；
  - 浅源 J-13（约 9 m），9 个频点：109、127、145、163、198、232、280、335、385 Hz，源级未公布。

| 深源组 | 源级 | 49–145 Hz 内的频点 |
|---|---|---|
| Set 1 | 158 dB | 49 64 79 94 112 130 |
| Set 2 | 132 dB | 52 67 82 97 115 133 |
| Set 3 | 128 dB | 55 70 85 100 118 136 |
| Set 4 | 124 dB | 58 73 88 103 121 139 |

  依据：`表/A2_transmit_list.csv`（含逐条依据与访问日期）。**本文使用的 100 Hz 在 Set 3（128 dB）。**

- **记录**：HLA North，J1312340（自 J131 23:40 GMT 起），27 个阵元，采样率 3276.8 Hz，每通道 9 830 400 点（3000 s），int16 大端 SIO 格式。

  - SHA-256：`0f663c14efab00b16500e82d56936cf95b4931c1ea1a2a4bcb815d93b56b66d3`
- **阵元选择**（运行估计器之前写定）：剔除削顶（|样点| ≥ 32000）以及 98–102 Hz 带内功率偏离各阵元中位数超过 6 dB 的阵元，在剩余阵元中选最接近中位数者。结果为**第 9 阵元**；27 个阵元全部正常。
- **几何**：据 GPS，记录中段约 1200 s 处为最近通过（距 HLA North 约 0.7 km）。900–1500 s 窗口跨过最近通过点，100 Hz 脊线在 600 s 内由约 100.20 Hz 降到约 99.97 Hz。

## 2. 复基带提取

对一段（窗口 + 两端各 10 s 保护段）原始记录做 DFT，精确取出中心频率 ±10 Hz 的频点，按 20 Hz 反变换，再丢弃保护段。中心频率必须落在 DFT 频点上（整数 Hz 与 5 s 倍数的窗口长度都满足）。每个窗口从原始记录一次连续读取，不拼接。

拼接注意：若把独立提取的 300 s 段拼成长记录，段边界处有约 2% 的相对误差（宽带背景的频域截断振铃）。需要样点级相位精度时，一律整段连续提取。

## 3. 可见性筛选（运行模块之前）

LOFAR：Hann 10 s、帧移 1 s。对每个 300 s 时段：

- `peak_excess_dB` = 频点 ±0.5 Hz 内最大值 − 两侧 [1, 2] Hz 环带中位数；
- `ridge_continuity` = 各帧在 ±0.5 Hz 内的峰值频率落在该段峰值频率中位数 ±0.2 Hz 内的帧比例；
- **通过**：`peak_excess_dB > 10` 且 `ridge_continuity > 0.6`。

94–109 Hz 的结果（`表/A3_visibility.csv`）：

| 频点 | 组 | 通过时段数 | 通过的时段起点 (s) | peak_excess 范围 (dB) |
|---|---|---|---|---|
| 94 | Set 1 | 10/10 | 全部 | 18.4–27.3 |
| 97 | Set 2 | 0/10 | — | 9.7–12.7 |
| 100 | Set 3 | 5/10 | 600, 900, 1200, 1500, 1800 | 10.9–18.0 |
| 103 | Set 4 | 2/10 | 900, 1200 | 9.0–22.0 |
| 106 | Set 5 | 0/10 | — | 9.6–15.3 |
| 109 | 浅源 | 10/10 | 全部 | 21.2–31.7 |

97 与 106 Hz 多数时段有 > 10 dB 的功率抬升，但脊线不连续，按判据记为不可见，没有替换成更容易的频点。以理论轨迹为管道中心的另一种连续性定义（A7，`表/A7_visibility_theory_pipe.csv`）下，100 Hz 为 4/10，103 Hz 只有 900–1200 s 通过。

## 4. 参考轨迹及其限制

两条参考轨迹（`表/A4_groundtruth.csv`）：

- **路线 1**：在 94 Hz 上用 VIT + SMR 跟踪，反推径向速度 $v_r=c(94/f_{94}-1)$，30 s 滑动平均，再预测其他频点；
- **路线 2**：拖船 GPS 距离历程 + 传播时延数值求解。

两条路线在 100 Hz 上的差 RMSE 0.0387 Hz；在 900–1200 / 900–1500 s 窗口内为 0.0196 / 0.0193 Hz。

**限制（写作时必须照顾到）**：

- **A8 同源检验未通过**：100 Hz 与 94 Hz 的频移斜率比为 0.317（95% 区间 [0.108, 0.877]），同一声源应为 1.064；109/94 为 0.481（预期 1.160）。所以不能确认所用 100 Hz 脊线与 94 Hz 来自同一声源的同一传播路径。
- 100 Hz 脊线与参考轨迹整体相差约 +0.084 Hz（A8），在 900–1500 s 评价区间内平均差 0.07 Hz（GPS）与 0.09 Hz（94 Hz 推算）。
- 参考轨迹只能用于图示，**不是接收相位真值**；实测部分只能用补偿谱评价，不能算 η。
- **A9**：103 Hz 在 900–1200 s 附近有一条约 0.15 Hz 外的竞争脊（逐帧中位间隔 0.145 Hz，68% 的帧峰同时匹配两者），来源未定。
- **A10**：约 103.7 Hz 有一条外来斜线（与 94 Hz 斜率比 5.7），未作目标归因；它距 100 Hz 窗口的修正邻域 2 Hz 以上，不影响 100 Hz 结果。

论文写法：100 Hz 是一条真实存在、连续可跟踪的窄带脊线，用它检验相干聚焦就足够了；不需要也不能声称确认了它的声源归属。

## 5. Phase D 中的扩展（已完成）

33 个发射频点（49–145 Hz）× 10 个 300 s 时段，按第 3 节判据在全长 LOFAR 上筛选并冻结，之后才运行任何模块。通过 105 个：浅源 30/30、强线（Set 1）60/60、弱线（Set 2–5）15/240（Set 2: 4，Set 3: 7，Set 4: 3，Set 5: 1）。连续可见的弱线段：100 Hz 600–2100 s（5 段）、52 Hz 600–1200 s、103 Hz 900–1500 s 等。结果见证据总表 #19 与 `08_PhaseD补充实验/04_外部验证_X1-X3/X3_多线谱实测/`。
